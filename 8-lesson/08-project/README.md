# Пример проекта для которого нужно добавить тесты

### Инструкция для разработки
1. Запуск происходит с помощью docker, он должен быть установлен в систему
2. Есть пример .env.example в котором определны переменные окружения для
   сервиса
   Скопируйте файл .env.example в .env `cp .env.example .env` и поменяйте настройки если надо

3. Есть Makefile в котором 2 команды
   Если указано IN_DOCKER=1 то запускается с помощью докера, эта опция по
   умолчанию

   - run -- запуск сервиса
   - tests -- запуск тестов, эта команда ожидается что будет запускаться в CI
   Примеры:
   - `make IN_DOCKER=0 tests` -- запустит тесты на локальной машине
   - `make run` -- запустит сервис с использованием докера

Примечания: настройки под запуск в pycharm, vscode, sublime, vim и прочие редакторы тут описаны не будут
